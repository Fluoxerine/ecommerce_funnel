# 分析方法论

> 所有方法均来自行业标准实践（GA4、Amplitude、CRO 行业框架），不虚构方法。

---

## 一、漏斗建模

### 1.1 页面级漏斗 (Page-Level Funnel)

按用户访问的页面类型构建漏斗层级：

```
Home（首页） → PLP（商品列表页） → PDP（商品详情页） → Cart（购物车） → Checkout（结算页）
```

每个步骤统计到达过该页面类型的**独立会话数**，计算：
- **上一阶段转化率**: `step_n / step_{n-1} × 100%`
- **整体转化率**: `step_n / step_1 × 100%`

### 1.2 行为级漏斗 (Event-Level Funnel)

按用户行为事件类型构建漏斗：

```
浏览(view) → 点击(click) → 加购(add_to_cart) → 购买(purchase)
```

与页面级漏斗互补：页面漏斗衡量"到了哪个页面"，行为漏斗衡量"做了什么动作"。

### 1.3 渠道专属漏斗

为每个流量渠道独立构建页面级漏斗，定位不同渠道的特有瓶颈环节。

### 1.4 严格路径漏斗 (Strict Sequential Funnel)

与页面覆盖分析互补，构建**必须按时间顺序**访问各页面的严格漏斗：

```
Home(首页) → PLP(列表页) → PDP(详情页) → Cart(购物车) → Checkout(结算页)
```

每步要求：前页首次访问时间 < 当页首次访问时间，即用户必须按顺序逐步深入。

**对比意义：**
- 页面覆盖分析衡量"触达广度"——多少会话到过每个页面（允许多入口）
- 严格路径漏斗衡量"路径深度"——多少会话按理想路径逐步深入（人数必递减）
- 两者差异 = 非理想路径流量（深链、回退、跳跃），反映真实用户行为的复杂性

### 1.5 深链流量分析

识别直接落地到商品列表页（PLP）而跳过首页的会话：

- **深链会话**: `has_plp AND NOT has_home`
- **首页路径会话**: `has_home AND has_plp`（首页→列表页 顺序）
- **仅首页会话**: `has_home AND NOT has_plp`

分渠道对比深链 vs 首页路径的转化率差异，量化首页的筛选价值。

## 二、多维度拆解

### 2.1 转化率分析

对各维度（渠道/设备/国家/忠诚度/获客渠道）计算：
- 总会话数、购买会话数
- 转化率 = 购买会话数 / 总会话数 × 100%
- 流量占比 = 该维度会话数 / 全量会话数 × 100%

### 2.2 停留时长分桶（GA4 标准）

采用固定行为阈值分桶而非等频分桶，原因：固定阈值对应真实用户行为阶段，可跨周期对比。

| 时长区间 | 行为含义 |
|:---|:---|
| <60s | 快速跳出 — 几乎无购买意向 |
| 60-180s | 浅层浏览 — 仅扫视少量页面 |
| 180-420s | 中度参与 — 有明确浏览行为 |
| 420s+ | 深度决策 — 高概率转化 |

参考：电商行业行为分桶最佳实践、Amplitude Behavioral Cohorts。

## 三、趋势归因分析

### 3.1 月度趋势

按年-月分组计算各月转化率，观察 3 年期间的长期趋势和季节性波动。补充年度均值线辅助趋势判读。

### 3.2 Shift-Share 归因分解

将转化率年度变化分解为两个效应：

- **结构效应**: 假设各渠道 CR 不变，仅渠道流量占比变化导致的 CR 变化。衡量"流量结构是否变得更偏向低质量渠道"
- **质量效应**: 假设渠道份额不变，仅各渠道内部 CR 变化导致的 CR 变化。衡量"渠道本身的转化能力是否下降"

```text
ΔCR = 结构效应 + 质量效应 + 交互效应（通常较小）
```

## 三、流失根因诊断

### 3.1 独立样本 t 检验 (Welch's t-test)

比较流失组 vs 转化组在特征（总停留时长、事件数）上的均值差异是否显著。使用 Welch's t-test（不假设方差齐性）。

### 3.2 Cohen's d 效应量

量化差异的**实际大小**（不仅是统计显著性），避免大样本下"显著性通货膨胀"。

```text
d = (M1 - M2) / SD_pooled
```

效应量判定: |d| < 0.2 小 | 0.2-0.5 中 | 0.5-0.8 大 | > 0.8 非常大 (Cohen, 1988)

### 3.3 渠道 × 流失环节矩阵

交叉分析每个渠道在每个流失环节的流失率，定位渠道特有的瓶颈。

## 四、损失量化

### 4.1 环节损失金额

```text
损失金额 = 流失会话数 × 已转化用户客单价
```

- 客单价基于已实际购买用户的 `total_revenue` 均值（避免虚构权重）
- 流失会话按漏斗层级联去重：同一会话在较早环节流失后，不计入后续环节的入环会话数
- 损失金额为估算值，假设流失用户如果转化，客单价与已转化用户相近

### 4.2 PIE 优先级矩阵

行业标准 CRO 优先级框架（WiderFunnel 方法论）：

```text
PIE = Potential × Importance × Ease
```

- **Potential** (1-10): 该环节损失金额占全链路损失的比例
- **Importance** (1-10): 该环节流量占全链路流量的比例
- **Ease** (1-10): 该环节的优化难度（越高越容易）

## 五、统计检验

### 5.1 卡方独立性检验

检验各维度（渠道/设备/国家/忠诚度）与"是否转化"之间是否存在显著关联。

### 5.2 Bonferroni 校正

由于同时检验多个假设（4 个维度），使用 Bonferroni 校正：

```text
α_corrected = 0.05 / n_tests = 0.0125
```

## 六、A/B 实验分析

对 `experiment_group` 字段（Control / Variant_A / Variant_B）进行：
- 各组转化率比较
- Control vs 各 Variant 的卡方检验
- 相对提升率计算: `(rate_variant - rate_control) / rate_control × 100%`
