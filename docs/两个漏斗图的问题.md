# 一、第一页漏斗（页面级漏斗）的问题

## 1. 漏斗人数倒挂（严重）

你图里的：

| 页面    | 会话数     |
| ----- | ------- |
| 首页    | 300,782 |
| 商品列表页 | 396,329 |

说明：

很多用户：

* 并不是从首页进入
* 可能直接进入列表页

例如：

* 搜索引擎SEO
* 广告落地页
* 推荐页
* APP push
* 活动页

所以：

### 你现在统计的其实是：

```text
“访问过该页面的会话数”
```

而不是：

```text
“严格按路径流转的会话数”
```

这是两个完全不同的概念。

---

# 2. 你其实做的是“页面覆盖分析”

而不是：

```text
严格漏斗分析
```

这个区别非常重要。

---

## 真正漏斗应该是：

```text
首页
→ 从首页进入列表页
→ 从列表页进入详情页
→ 从详情页进入购物车
→ 从购物车进入结算
```

人数必须递减。

---

# 3. 你用了“交叉转化率”

这是你图里最大的问题之一。

你写的是：

```text
交叉转化率 = 同时到达前后两页的会话 / 到达前页的会话
```

这本质上是：

```text
Overlap Rate
```

不是：

```text
Sequential Funnel Conversion
```

---

## 举个例子

用户路径：

```text
详情页
→ 首页
→ 离开
```

他：

* 到达了首页
* 到达了详情页

于是：

会被统计进：

* 首页
* 详情页

甚至可能被算进交叉转化。

但实际上：

> 根本没有从首页→详情页。
