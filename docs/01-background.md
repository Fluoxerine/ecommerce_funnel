# 项目背景

## 业务问题

电商平台面临的核心增长问题：用户在站内行为路径中大量流失，但不清楚流失发生在哪个具体环节、哪个渠道、哪个品类，无法量化流失带来的收入损失，缺乏基于数据的优化优先级排序。

## 分析目标

1. **漏斗拆解** — 构建页面级和行为级双漏斗，定位核心流失环节
2. **多维诊断** — 按渠道/设备/国家/品类/用户分层定位不同维度下的差异化流失模式
3. **损失量化** — 基于真实交易数据量化各环节损失金额
4. **优先级输出** — PIE 矩阵排序优化方向，输出可落地的策略建议
5. **效果框架** — 建立优化前后的基准快照对比机制，支持 A/B 实验效果评估

## 数据来源

基于 E-Commerce Transactions + Clickstream 公开数据集，包含 2021-2023 三年间的用户行为事件、交易订单、用户画像、商品目录和广告活动五张核心表，共 2.2M+ 条记录。

## 分析框架

采用电商行业标准的六阶段漏斗分析闭环：

```
目标定口径 → 数据全采集 → 漏斗拆流失 → 根因深诊断 → 策略强落地 → 复盘再迭代
```

## 适用范围

- 电商零售 / DTC 品牌 / 跨境电商的转化率优化
- 增长团队的数据驱动决策
- CRO（Conversion Rate Optimization）专项分析
