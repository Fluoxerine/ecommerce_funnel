# Power BI Dashboard

> Ecommerce Funnel CRO — 4-page interactive report

## Data Files

All CSV exports are in `powerbi/data/` (generated by `python python/import_to_mysql.py`):

| File | Content | Use |
|------|---------|-----|
| `funnel_wide_export.csv` | 5,000 sessions x funnel steps | Main fact table |
| `funnel_overview.csv` | Funnel step flags + conversion | Funnel visual |
| `channel_analysis.csv` | 4 rows, channel-level conversion | Channel comparison |
| `device_analysis.csv` | 3 rows, device-level conversion | Device comparison |
| `country_analysis.csv` | 7 rows, country-level conversion | Geographic analysis |

## Report Pages

| Page | Key Visuals | Data Source |
|------|-------------|-------------|
| ① Funnel Health | KPI cards (traffic, conversion, loss), funnel chart | funnel_overview.csv |
| ② Traffic Quality | Channel x Device matrix, channel conversion bars, time heatmap | channel_analysis.csv, device_analysis.csv |
| ③ Churn Diagnostics | Loss waterfall, churn rate by dimension, lost vs converted comparison | funnel_wide_export.csv, channel_analysis.csv |
| ④ Priority Matrix | PIE scatter plot, optimization ranking table | computed from analysis results |

## Quick Start

1. Open Power BI Desktop
2. Get Data → Text/CSV → Select files from `powerbi/data/`
3. Load all 5 CSV files
4. Set up relationships if needed (SessionID across tables)
5. Build visuals per page specification above

## PBIR Report

The `funnel_report/` folder contains a PBIR (Enhanced Report Format) project:

```
funnel_report/
  Ecommerce Funnel CRO.Report/
    definition.pbir
    definition/
      version.json
      report.json
      pages/
        pages.json
        funnel_health/page.json
        traffic_quality/page.json
        churn_diagnostics/page.json
        priority_matrix/page.json
```

To preview: `pbi report preview`
To convert: `pbi report convert`
